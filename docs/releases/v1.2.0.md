TypePilot 1.2.0 makes anonymous usage reporting more useful, so it's clearer which features help, what's slow and what breaks. Download **TypePilot.apk** below.

### Changed
- **Share anonymous usage** (Settings → Apps, memory & privacy) now also covers: suggestions dismissed or ignored, how AI requests end (ok, empty, cancelled or an error category) with a response-time bucket, rewrites and drafts applied or discarded, saved phrases and facts added or edited, memory size buckets, which screens and settings are used (on/off and fixed choices only), setup steps and permission states, accessibility turning on or off, typing and app session length buckets, the *kind* of app you typed in (chat, email, browser or other, decided on the phone), model downloads, and caught errors as well as crashes.
- It still never shares what you type, your memory, document or file names, app or package names, model names, hosts or API keys. Errors carry the exception type and stack, not the message.
- Reports are sent in smaller batches, so a busy day can't exceed the server's limits.

### Notes
- Same signing key as 1.1.0: installs over it, no uninstall needed.
- Turning sharing off still stops reporting and deletes everything this install sent.
