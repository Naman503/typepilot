TypePilot 1.1.0 adds anonymous usage reporting, so it's clear which features help and what breaks. Download **TypePilot.apk** below.

### Added
- **Share anonymous usage** (Settings → Apps, memory & privacy), on by default. It shares which features are used, daily counts of suggestions shown and accepted, setup steps, the AI provider *type* (Gemini, Groq, on-device…), the keyboard family and crashes, with a random id made on first run.
- It never shares what you type, your memory, app names, model hosts or API keys. Crash reports carry the exception type and stack, not the message.
- Turning it off stops reporting and deletes everything this install sent.

### Changed
- The accessibility disclosure and the privacy section mention usage reporting.

### Notes
- Same signing key as 1.0.0: installs over it, no uninstall needed.
